## 資料來源

`/tpch-pos-demo/` 之菜單（99 品項 / 14 分類）、價格、售罄狀態、規格彈窗分組、
套餐彈窗分組與菜品照片，均取自門店現行點餐系統的實機頁面快照（2026-09-28）。
框架為 ag-pos takeawaypayV2（Framework7 + Vue），示範頁依原結構重建，樣式取原系統 CSS 變數。

`/tpch-demo/` 為推廣活動機制的構想示範。
